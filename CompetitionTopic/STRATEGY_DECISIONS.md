## 一.5 角色固化（用户指定）

| 角色 | 绑定 | 职责 | 优先级 |
|---|---|---|---|

| **修理工** | worker[0]（ID 最小） | D1-D2 自由采石建墙；D3+ 白天**只采购**（墙券/修复券）+建补墙+采集；**夜间执行围墙升级/修复**（升级=回血，省修复包） | 1吃药 |
| **挖矿工** | worker[1] | 全天 采矿→卖钱→返回 循环 | 1吃药 > 2(D1 石头>20 且墙<14)紧急建墙 > 3持续外出采矿（躲避机器人/判路径） |

**修理工夜间触发**：D3+ 夜间**始终优先**尝试升级（用白天采购的券）→ 抢修受损墙 → 无事才采矿（用户：白天最大化采集；机器人到墙有回合数，夜间升级来得及）。
**修理工抢修口径（用户补充 2026-09-22）**：修复阈值 = 墙血 <50%；正面墙优先；L1/L2 优先用升级券（升级=回满血+提上限），L3 升级券失效 → 只能用 WallFixer；无达标需求/无券 → 落回采矿。
**挖矿工售卖**：背包满 / 路过 vendor / 需要凑武器升级费 → 走向 vendor 卖出。

## 三、术语定义（防歧义）

| 术语 | 定义 |
|---|---|
| **安全矿（B 方案）** | **以"机器人行军走廊"判定**：走廊 = 出生点质心 → 我方基地 的连线（半宽 CORRIDOR_WIDTH=5），但**只算距我方基地 > CORRIDOR_BASE_MARGIN=8 的部分**（近基地处有墙/炮塔保护）。矿落在走廊内 → 危险（夜间/临近入夜不采）。辅以 MAX_MINE_DIST=16（优先近矿）与"绝不深入敌方侧" |
| **敌方矿 / 我方矿** | 矿本身中立；"敌方侧"= 距**敌方基地更近**的矿（一律不选）。真正的安全判据是上面的**行军走廊** |
| **FRONT（正面）** | 迎敌侧（墙环朝向机器人来向的那一侧）；对应 CP 的**背面**（炮台/开口侧背向来敌） |
| **CP（控制点）** | 开拓者站位，与 3 炮台两两相邻，一站控 3 炮 |
| **出生走廊** | 历史夜间机器人出生点附近（全局唯一且每晚固定），夜间避开 |
| **Mine Lock** | 工人锁定一个矿直到采完（10次/消失）；背包达 60% 批量阈值时释放去卖 |
| **围墙状态表（WallRegistry）** | 跨回合 Dict：Pos → {exists, level, health, is_front, breached_round, rebuilt_round}；只记事实，供修复/升级决策 |
| **补建墙** | 前夜被攻破、次日白天由修理工重新建起的墙；**回到 L1**，须重新纳入升级队列（优先于普通健康墙） |
| **达标修复** | 墙血 < REPAIR_HP_RATIO(0.5)；L3 只能用 WallFixer，L1/L2 优先升级券 |

## 四、布局规范（BaseLayoutPlanner）

以左上基地为例（实际朝向由 FRONT 参数旋转/镜像生成，禁止硬编码）：

```
|空白|围墙|围墙|围墙|围墙|围墙|
|空白|空白|空白|空白|空白|围墙|
|空白|炮台|基地|基地|空白|围墙|
|空白|人物|基地|基地|空白|围墙|
|空白|炮台|炮台|空白|空白|围墙|
|空白|围墙|围墙|围墙|围墙|围墙|
```

- 基地 2×2；**蓝区=距基地切比雪夫 1 格（建武器，12 格）；黄区=距基地 2 格（建墙，20 格）**；墙建三侧共 **14 格**，FRONT 开口侧不建。
- 3 炮台与 CP 两两相邻；凑不齐 3 炮时布局器自动迁移 CP。
- 建墙顺序：**正面（迎敌侧，离 CP 最远）最优先**，再到侧面。
