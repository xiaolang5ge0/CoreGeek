## 三、术语定义（防歧义）

| 术语 | 定义 |
|---|---|
| **安全矿（B 方案）** | **以"机器人行军走廊"判定**：走廊 = 出生点质心 → 我方基地 的连线（半宽 CORRIDOR_WIDTH=5），但**只算距我方基地 > CORRIDOR_BASE_MARGIN=8 的部分**（近基地处有墙/炮塔保护）。矿落在走廊内 → 危险（夜间/临近入夜不采）。辅以 MAX_MINE_DIST=16（优先近矿）与"绝不深入敌方侧" |
| **敌方矿 / 我方矿** | 矿本身中立；"敌方侧"= 距**敌方基地更近**的矿（一律不选）。真正的安全判据是上面的**行军走廊** |
| **FRONT（正面）** | 迎敌侧（墙环朝向机器人来向的那一侧）；对应 CP 的**背面**（炮台/开口侧背向来敌） |
| **CP（控制点）** | 开拓者站位，与 3 炮台两两相邻，一站控 3 炮 |
| **出生走廊** | 历史夜间机器人出生点附近（全局唯一且每晚固定），夜间避开 |
| **Mine Lock** | 工人锁定一个矿直到采完（10次/消失）；背包达 60% 批量阈值时释放去卖 |

## 四、布局规范（BaseLayoutPlanner）

以左上基地为例（实际朝向由 FRONT 参数旋转/镜像生成，禁止硬编码）：

```
|空白|围墙|围墙|围墙|围墙|围墙|
|空白|空白|空白|空白|空白|围墙|
|空白|炮台|基地|基地|空白|围墙|
|空白|人物|基地|基地|空白|围墙|
|空白|炮台|炮台|空白|空白|围墙|
|空白|围墙|围墙|围墙|围墙|围墙|
```

- 基地 2×2；**蓝区=距基地切比雪夫 1 格（建武器，12 格）；黄区=距基地 2 格（建墙，20 格）**；墙建三侧共 **14 格**，FRONT 开口侧不建。
- 3 炮台与 CP 两两相邻；凑不齐 3 炮时布局器自动迁移 CP。
- 建墙顺序：**正面（迎敌侧，离 CP 最远）最优先**，再到侧面。
