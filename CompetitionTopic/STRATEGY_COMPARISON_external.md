## 二、外部有、本队值得学习（建议采纳，非分歧）

| # | 机制 | 外部做法 | 本队现状 | 建议 |
|---|---|---|---|---|
| L1 | **返程 deadline（BFS）** | `当前回合+返程BFS距离+6 ≥ deadline` → 进入返回阶段 | 修理工用 A\* 路径 +4 余量；**矿工无返程 deadline**（整夜采） | 给矿工加"入夜前返程"（避免夜采被兵潮顺路杀） |
| L2 | **路径避射（Bresenham+墙遮挡）** | 目标格暴露在机器人射击线内 → 绕行不暴露邻格 | 仅"机器人≤3格→直接远离" | 移动层加射击线遮挡判定，比单纯远离更稳 |
| L3 | **振荡逃生阀（8步≤4种位置）** | 触发后 8 回合强制远离历史位置 | 已加"两格 A→B→A"检测 | 可扩展为"窗口内位置种类"更鲁棒 |
| L4 | **移动失败绕行** | 记录连续失败的目标格，下次避开 | 有 unstuck（清目标），无失败格记忆 | 加失败目标格短期黑名单 |
| L5 | **空动作兜底** | 无命令时→走向基地（>2格）；≤2格→走任意邻格 | 部分分支会返回 None（如等待建墙派单） | 兜底"永不空转"，避免修理工卡墙外类问题复发 |
| L6 | **非关键角色保护** | 机器人≤3格 + 低血 → 删命令→吃药→逃安全格 | 修理工靠夜间抢修/repair_post，无独立"低血逃离" | 加"修理工被贴脸且低血→优先逃离" |
| L7 | **墙破当回合先逃** | 墙数减少=缺口→当回合逃向墙内安全格，下回合再修 | 有 WallRegistry 攻破检测，但当回合不逃 | 复用 registry 攻破事件→当回合躲避 |
| L8 | **答案安全校验** | 全零/重复/分页不全/401 → 不提交 | **已补**（全零/error/占位符） | ✅ 已实现（重复/分页可再补） |
| L9 | **命令预算 6 → 强制提交** | 已用命令数 ≥6 → 强制要答案 | 按 timeout 收紧 LLM 循环（≤8） | 可加"命令计数"上限 |
| L10 | **跨任务经验复用（上限12）** | 从成功/失败命令学习认证头/参数名，跨任务复用 | 有 SOP 自进化（前 2 任务后提取） | 把"API 认证/参数命中"持久化复用 |

## 三、分歧点（需你决策）

### D1. 修理工 D2–D3 是否外出采矿？
- **本队**（你已指定）：D2–D3 修理工外出采铜/铁卖钱买券，常备 5 石头；D4+ 才回防。
- **外部**：D3+ 修理工**固定墙内**（维修/升级/买物资），不外出。
- **影响**：外出多一份经济 vs 墙内待命更安全/更早维修。
- **我的建议**：维持本队（你已拍板 D2–D3 采矿）——但可加一条：**墙有缺口时立即回内圈补墙**。

### D2. 归位余量
- **本队**：炮手 3 回合；修理工 4 回合。
- **外部**：炮手 6 回合；修理工 3 回合。
- **影响**：炮手余量偏小可能在夜临时才到炮位（少打 1–2 发）；修理工余量偏大则提前离开采集。
- **我的建议**：炮手 3→5、修理工 4→3（贴近外部，且我们已用 A\* 实际路径）。

### D3. 升级/购买优先级：武器优先 vs 紧急优先
- **本队**：武器L2 → 受损墙 → FRONT墙L2 → 武器L3 → 墙全L2 → 墙L3 → 基地 → 备货（**武器整体推进优先**）。
- **外部**：紧急墙券 → 紧急修复剂 → 武器券 → 常规修复剂 → 常规墙券（**应急优先**）。
- **影响**：外部在墙危急时先补墙；本队在武器没升完前压制墙升级（曾修过"廉价墙券吃光金币"）。
- **我的建议**：折中——保留武器优先，但**墙 HP 低于动态阈值时插队**（外部式应急）。

### D4. 是否升级基地？
- **本队**：金≥250 升基地（视为后期保险）。
- **外部**：明确**不升级基地**（金币留给武器/任务）。
- **影响**：基地升级 = 花钱买 1500 血库；前期性价比低。
- **我的建议**：维持"金≥250 才升"，或改为**只在武器/墙全满后**再升（更省）。倾向后者。

### D5. 修理工夜间是否用武器券升级武器？
- **本队**：武器升级专属炮手（白天）；修理工只升级/修复墙。
- **外部**：修理工夜间"用武器券主动升级武器（保持火力）"。
- **影响**：夜间烟火的武器升级能即时提升火力，但需修理工持有武器券（占用背包/金币）。
- **我的建议**：暂不采纳（职责分离更清晰），除非实战发现武器升级长期滞后。

### D6. 矿工夜间是否继续采矿 / 有无返程 deadline？
- **本队**：矿工整夜采矿（有安全半径/规避，但无返程 deadline）。
- **外部**：夜间可继续采矿，但 **deadline 驱动返程** + 多层保护；靠近基地有威胁时**不发命令原地待命**。
- **影响**：夜采收益 vs 被兵潮顺路杀的风险（我们此前已因夜采死过工人）。
- **我的建议**：采纳外部"**返程 deadline + 近基地威胁停发**"（L1/L4），保留夜采收益但更安全。

### D7. 任务命令预算：6 条 vs timeout
- **本队**：`min(8, timeout-2)` 次 LLM 循环 + 3 次非 JSON 强退。
- **外部**：命令数 ≥6 → 强制提交（force_answer 模式只准给答案）。
- **我的建议**：采纳"命令计数 ≥6 → 进入 force_answer"（比单纯循环上限更贴任务语义），与现有上限叠加。

### D8. 弹药/物资上限
- **本队**：WallFixer 常备 2（上限 3）；墙券按需批量。
- **外部**：墙券/修复剂**各上限 4**。
- **我的建议**：维持本队（更省金币），或上限提到 4（D5+ 多 BOSS 夜更稳）。

## 四、结论

- 两队**大方向高度一致**（3火箭+墙环、角色固定、双层新闻、寻宝 LLM 推断、确定性任务优先）。
- **值得直接学习**：L1 返程 deadline、L2 路径避射、L5 空动作兜底、L6/L7 修理工安全（贴脸逃离/墙破先逃）、L9 命令预算、L10 跨任务 API 经验复用。
- **分歧点 D1–D8** 请你逐条拍板；我的建议已列在各条末尾（默认倾向"保留本队已拍板项 + 采纳外部安全/鲁棒项"）。
- 已顺手采纳的两项（两边一致、纯安全）：**答案安全校验**、**寻宝计划校验 + 召唤结果处理**（见本轮提交）。
