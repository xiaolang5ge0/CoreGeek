## 二、外部有、本队值得学习（建议采纳，非分歧）

| # | 机制 | 外部做法 | 本队现状 | 建议 |
|---|---|---|---|---|
| L1 | **返程 deadline（BFS）** | `当前回合+返程BFS距离+6 ≥ deadline` → 进入返回阶段 | 修理工用 A\* 路径 +4 余量；**矿工无返程 deadline**（整夜采） | 给矿工加"入夜前返程"（避免夜采被兵潮顺路杀） |
| L2 | **路径避射（Bresenham+墙遮挡）** | 目标格暴露在机器人射击线内 → 绕行不暴露邻格 | 仅"机器人≤3格→直接远离" | 移动层加射击线遮挡判定，比单纯远离更稳 |
| L3 | **振荡逃生阀（8步≤4种位置）** | 触发后 8 回合强制远离历史位置 | 已加"两格 A→B→A"检测 | 可扩展为"窗口内位置种类"更鲁棒 |
| L4 | **移动失败绕行** | 记录连续失败的目标格，下次避开 | 有 unstuck（清目标），无失败格记忆 | 加失败目标格短期黑名单 |
| L5 | **空动作兜底** | 无命令时→走向基地（>2格）；≤2格→走任意邻格 | 部分分支会返回 None（如等待建墙派单） | 兜底"永不空转"，避免修理工卡墙外类问题复发 |
| L6 | **非关键角色保护** | 机器人≤3格 + 低血 → 删命令→吃药→逃安全格 | 修理工靠夜间抢修/repair_post，无独立"低血逃离" | 加"修理工被贴脸且低血→优先逃离" |
| L7 | **墙破当回合先逃** | 墙数减少=缺口→当回合逃向墙内安全格，下回合再修 | 有 WallRegistry 攻破检测，但当回合不逃 | 复用 registry 攻破事件→当回合躲避 |
| L8 | **答案安全校验** | 全零/重复/分页不全/401 → 不提交 | **已补**（全零/error/占位符） | ✅ 已实现（重复/分页可再补） |
| L9 | **命令预算 6 → 强制提交** | 已用命令数 ≥6 → 强制要答案 | 按 timeout 收紧 LLM 循环（≤8） | 可加"命令计数"上限 |
| L10 | **跨任务经验复用（上限12）** | 从成功/失败命令学习认证头/参数名，跨任务复用 | 有 SOP 自进化（前 2 任务后提取） | 把"API 认证/参数命中"持久化复用 |

## 三、分歧点（已决策 2026-09-23）

| # | 分歧 | 决策 | 落地 |
|---|---|---|---|
| D1 | 修理工 D2–D3 | **D2-D3 外出采矿；D3+ 夜间回防，直到机器人清空才考虑外出采矿** | `RETURN_STICKY_DAY=3`；夜间机器人存活则守 repair_post |
| D2 | 归位余量 | **炮手 5 / 修理工 3** | `DUSK_MARGIN=5`、`REPAIR_MARGIN=3` |
| D3 | 升级优先级 | **武器优先；墙血低于动态阈值时可插队** | `wall_hp_threshold(day)=max(100,(day+1)×100)`，优先级 5 |
| D4 | 是否升基地 | **暂不升；武器+墙全 L3 后才升** | 基地任务门控 `all_weapons_l3 and all_walls_l3` |
| D5 | 修理工夜升武器 | **暂不考虑**（武器由炮手专职） | 不变 |
| D6 | 矿工夜采/返程 | **采纳外部**：返程 deadline（白天70/夜间130）+ 基地受威胁且矿工在基地3格内→原地待命 | `_past_return_deadline` + base_threat 检查 |
| D7 | 任务命令预算 | **命令 ≥8 强制提交**（采纳命令计数） | `FORCE_SUBMIT_CMDS=8` |
| D8 | 物资上限 | **金币紧缺时上限 4；武器+墙全升满后不设上限** | `FIXER_STOCK_MAX=4`、`FIXER_STOCK_MAXED=8` |

> 注：外部策略书对比结论中的"值得学习"项（L1/L2/L5/L6/L7/L9/L10）尚未全部实现，后续按需采纳。

## 四、结论

- 两队**大方向高度一致**（3火箭+墙环、角色固定、双层新闻、寻宝 LLM 推断、确定性任务优先）。
- **值得直接学习**：L1 返程 deadline、L2 路径避射、L5 空动作兜底、L6/L7 修理工安全（贴脸逃离/墙破先逃）、L9 命令预算、L10 跨任务 API 经验复用。
- **分歧点 D1–D8** 请你逐条拍板；我的建议已列在各条末尾（默认倾向"保留本队已拍板项 + 采纳外部安全/鲁棒项"）。
- 已顺手采纳的两项（两边一致、纯安全）：**答案安全校验**、**寻宝计划校验 + 召唤结果处理**（见本轮提交）。
