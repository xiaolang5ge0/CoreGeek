## 1. 问题二真相：IKK7EE"夜间不攻击"= Day4 夜团灭

### 现场还原（IKK7EE Night4, r461-520）

1. r461-502：138 只夜潮涌入，火力轮转正常击杀，剩 2 只（hp220@(12,21)、hp10@(11,21)）。
2. **r504-519（16 回合）：炮每回合开火（atk=1），fb_fail 每回合报失败（10042/10040/10041 轮流），2 只敌人 hp 纹丝不动**。
3. 同期 station 被啃：640→40（每回合 -40），**无任何反制**（worker 在夜采/赶路，无修复、无变更目标）。
4. r520：roles=[]、墙 0、炮 0 —— **全队阵亡**。之后 6 天空壳跑完（c=null）。

### 根因（数据实锤，三场通用）

**火箭实际冷却 ≠ request 里 cooldown 字段**：

| 同炮距上次开火 | 成功 | 失败 |
|---|---|---|
| ≤4 回合 | **0** | **145** |
| ≥5 回合 | **734** | 45（另查明全是匹配误差） |

- 任务书写冷却 3 回合；实测**间隔 5 回合才稳定成功**（实际冷却 4）。
- 接口文档明示"cooldown 仅火箭有"——但**request 的 cooldown 字段全程恒 0，不可信**。
- `fire.py` 只在 `w.cooldown == 0` 时选炮 → 认为就绪 → 实际冷却中 → 开火失败（裁判判"冷却中"）→ 敌人无伤。
- fire.py **完全不消费 fb_fail 反馈**，失败后继续同炮同目标硬打。
- 对照 IKK7EF 同期 r502-519：**同样 16 回合攻击全失败**（fb_fail 循环），只是它敌人没啃基地，苟活。

### 次生问题

- station 掉血无响应：无"基地受击→最高优先反制"通路（WallFixer 只修墙；station 不可修，只能杀敌或升级）。
- 3 炮全火箭：冷却期整夜火力真空。**加特林/电磁冷却恒 0**（接口文档原文）——武器混编的实证价值出现。

## 2. 问题一：自进化任务逐个清点

### 任务成绩单（✅提交 ❌未提交）

| 任务 | IKK7EF | IKK7EE | IKK7ED |
|---|---|---|---|

| l2 日志分析 | ❌ 死循环 | ❌ 死循环(4次) | ❌ 死循环 |
| l3 日志分析 | ✅ r287(重提r293) | ❌(D4 被打断) | ⚠️ r300 提13→错，r308 提27 |
| s3 脚本 | ❌ 被宝藏 LLM 打断 | ❌(D3 被打断) | ✅ r415 |

### 根因 A：`_answer_suspect` "error" 子串误杀（l1/l2 全灭）

- l1/l2 的**任务要求答案格式就是 `{"errors": {...}, ...}`**（错误统计）。
- `task.py _answer_suspect()` 检查 `("401","403","error","traceback",...) in low` → **answer 的 key "errors" 含子串 "error" → 永远判"查询失败"→ 永不提交**。
- LLM 每回合给同一答案 → 每次被拒 → 死循环到任务超时（phaseTask 清空，task_end，白做一整天，**任务点还被占满一天**）。
- l3 答案 `{"total_events":...}` 不含 "error" → 提交成功。**完美吻合全部样本**。
- IKK7ED l3 两次提交是因为第一次答案数值错（errorCode=2 "键值比对不通过: $/total_events"，errors 里有记录）→ 重答机制工作正常。

### 根因 B：宝藏 LLM 与任务 LLM 抢占同一 llmResp 通道

- llmResp 全局一条通道。D4 s3 执行中，宝藏推断 LLM（treasure_llm）触发 → **任务会话收到的是宝藏 JSON**（`{"x":20,"y":17,"items":[...]}`）→ 解析后无 cmd/answer → 空转 → 反复错位直到 s3 超时（IKK7EF r132-140、IKK7EE r229-239 的 llm 字段全是宝藏 JSON）。
- IKK7ED 的 s3 逃过一劫（宝藏 LLM 触发时机未撞上关键回合）。

### 其他

- l1/l2 死循环期间任务点被占满一整天 + 任务没提交 → **每场损失 2 任务 ×~100 分**。
- l3 重复提交（r287+r293）：提交后未立即确认成功，又发起一轮重算——浪费回合与 LLM 额度。
