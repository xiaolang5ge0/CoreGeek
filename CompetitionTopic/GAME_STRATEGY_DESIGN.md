# 《未来战争》GAME_STRATEGY_DESIGN v1.0

> 本文档回答"怎么赢"，给出多套总体打法与推荐初步策略。最终拍板见 STRATEGY_DECISIONS.md（待用户确认后生成）。

## 1. 怎么赢 / 怎么输

### 1.1 输的方式（按致命程度排序）
1. **基地先于对方被毁 → 直接判负，无视积分**。这是最硬的约束：一切经济/任务/击杀都建立在"基地活得比对方久"之上。
2. 半场结束时积分低于对方（双方都活着，或同时同分被毁）。
3. 异常5次 → 代码被停调度 ≈ 慢性死亡（工程问题，不是策略问题）。

### 1.2 赢的积分结构
| 来源 | 量级估算 | 可控性 |
|---|---|---|
| score3 生存分 | 全活10天=**550**（第10天单日就值100） | 高（防守质量直接决定） |
| score2 击杀分 | 取决于夜潮规模（UNKNOWN）；假设中后期每晚30~60分，全场约200~400 | 中（火力配置决定清潮效率） |
| score1 任务分 | 单任务约50+速度加成，2个任务点轮转，乐观估计全场200~400 | 中（开拓者时间+LLM/沙盒能力） |
| 宝藏 | "大量积分与金币"，一次性 | 低~中（推断难度未知） |

**结论：生存 > 击杀 ≈ 任务 > 宝藏。防守是第一优先级，经济与任务是为防守服务的手段。**

### 1.3 生存与积分的关系
- 活得久本身给分（550），且活着才能持续拿击杀分/任务分——生存是积分的**乘数**而非加数。
- 反过来，为了多采几回合矿、多做一个任务而牺牲基地血量，只有在"TTF（Time To Failure）足够安全"时才值得。

## 2. 核心资源交换关系

### 2.1 Gold 的真正作用
Gold 不直接产生积分，它购买的是**生存能力与击杀效率**：武器(25)、升级券(100/150)、修墙包(10)、药(10)、炸弹/眩晕(100)、召唤令(PvP)。**Gold 的边际价值随防线完整度递减**：防线没成型前每一金都关键；成型后多余的金才考虑升级/消耗品/召唤令。

### 2.2 工人回合的机会成本
- 1工人回合 ≈ 1矿石 ≈ 石头1金 / 铁3金 / 铜5金（示例价），或 1次建造/拆除，或若干格移动。
- **白天工人回合是全场最稀缺资源**：每天只有 2工人×70回合=140 工人回合，要在采矿/建造/卖货/跑图之间分配。
- 跑图是纯损耗：矿越远，"有效采集率"越低。选矿原则：**单位回合收益 = 矿价 / (往返路程+采集回合)**，铜虽贵但远矿不如近石。
- 卖矿需要站到小贩旁：一次往返卖货 ≈ 损失 2×路程 采集回合 → **批量卖**（背包攒多再卖）摊薄路费。

### 2.3 开拓者回合的机会成本
开拓者三种用法互斥：① 白天做任务（分+金）/ 推宝藏；② 夜间操控武器（单人守家时他必须守）；③ 白天也可以卖矿/买券跑腿。夜间防守是硬需求，任务只能插白天的空。

### 2.4 Wall / Weapon / Base Upgrade 谁更重要
- **Weapon > Wall > Base Upgrade**。武器同时提供生存与击杀分（一石二鸟）；墙只提供生存；基地升级（100/150金）本质上=花金买 1500/1500 点临时血库+回满血，是"后期的保险"。
- 升级=回满血的规则使**升级券兼具修复功能**：与其用 WallFixer(10金) 修墙，不如在墙快破时升级(20金) 回血+提升上限，性价比视墙存量而定。
- 初始75金=恰好3武器，Day1 的最优解几乎被锁死：**Day1 必须建成3武器，否则第一夜火力永远落后**。

### 2.5 任务什么时候值得做
- 任务给分+给金，且执行期间 LLM 不限次——任务期是用 LLM 处理复杂决策（如宝藏推断）的免费窗口。
- 但开拓者离岗=白天少一个跑腿/夜间防守的核心成员白天疲惫（位置）；且"离开任务点一格"即任务结束，机会成本是开拓者被钉在任务点。
- **判据：防线已成型 + 夜间火力达标 + 任务奖励/耗时比高于同期采矿期望 → 做；第一夜前一律不做。**

### 2.6 夜间采矿是否值得
collect 未限昼夜（STRONG_INFERENCE）。夜间采矿的收益=经济不中断；代价=少1~2个武器操控者+工人有被机器人顺手攻击的风险（机器人只打挡路的，避开路径则安全）。**前提：单人守火力足够清潮，且矿点不在机器人行进路径上。**

### 2.7 什么时候必须牺牲经济回防
用 TTF 估计：预估当前波次对墙/基地的伤害速率，当 "预计防线被突破回合 < 本夜剩余回合" 时，全员回防（工人补位操控武器/修墙/用炸弹）。具体阈值在 STRATEGY_DECISIONS 中定。

## 3. 三套总体打法

### 方案A：保守生存流（Bootstrap Defense）
- **经济**：Day1 双工人全力采石建墙，墙成型后才转铁/铜；夜间工人不采矿，全员守家。
- **防御**：20墙全封（若可建造区允许），基地只留一个由重兵把守的口或不封口。
- **武器**：加特林+电磁+火箭 各1（均衡火力，近中远覆盖）。
- **开拓者**：白天纯任务/跑腿，夜间守火箭。
- **优点**：第一夜几乎必活，TTF 高，适合摸清机器人曲线；**缺点**：经济慢，中期升级滞后，击杀分一般。

### 方案B：平衡流（Aggressive Economy + Solo Night Guard）—— **推荐**
- **经济**：Day1 双工人采石到够 FRONT+FLANK 墙（约8~12石），立即建3武器；Day2 起转铜/铁为主，夜间双工人继续采矿（若实测安全），卖货批量进行。
- **防御**：FRONT（朝敌/朝机器人来向）+ FLANK 重防，Rear 留 Service Gate 供工人出入，夜间视情动态封门。
- **武器**：**2火箭+1电磁**（AOE清群+点杀大怪）起步，备选 3火箭 实测对比。
- **开拓者**：白天任务为主，夜间单人值守（优先守火箭）；工人在 TTF 告警时被召回。
- **优点**：经济与防御兼顾，中期金币领先→升级领先→击杀分领先，滚雪球；**缺点**：第一夜墙少，对机器人曲线判断错误会有惊险时刻，需要 Telemetry+TTF 兜底。

### 方案C：激进压制流（Rush & PvP）
- **经济**：最少量墙（甚至第一夜裸奔靠武器+基地血硬扛），全力采铜冲经济。
- **武器**：3火箭快速升 L3（全图射程），火力碾压拿击杀分。
- **PvP**：经济富余后买召唤令压制对方夜晚，逼迫对方把金币花在防守上。
- **优点**：上限最高（击杀分+对方崩盘的额外收益）；**缺点**：第一夜赌博成分大，一旦机器人数量超预期直接判负，**不建议在机器人曲线 UNKNOWN 的初期采用**。

## 4. 推荐初步策略

**采用方案B（平衡流），按证据驱动逐步放开激进度：**

| 阶段 | 策略要点 |
|---|---|
| Day1 白天 | 双工人采石→建 FRONT+FLANK 关键墙 + **75金全建3武器**（2火箭+1电磁，建在基地相邻蓝色区）；开拓者不远离基地，熟悉地图 |
| Night1 | 三人各守一座武器，全员守家；记录机器人数量/出生点/路径（Telemetry） |
| Day2~3 | 经济转铜/铁，验证夜间采矿安全性；开拓者开始接第一个自进化任务（顺带用免费LLM推断宝藏线索） |
| 中期 | 金币优先升级武器（火箭优先，升=回血），墙快破时用升级券回血；TTF 告警即全员回防 |
| 实验项 | 2R+1Q vs 3R 对比（Replay+实战 A/B）；动态封门；宝藏推断；确认优势后再启用召唤令 PvP |

**暂不做**：召唤令 PvP、激进裸奔、宝藏强推（均标记 EXPERIMENT，待曲线摸清后评估）。

## 5. 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| 蓝/黄建造区未知，Demo 式任意建造可能大量失败 | Day1 防线建不起来 | 试探建造+反馈学习 BuildableMap；墙位设计带备选格 |
| 第一夜机器人数量超预期 | 直接判负 | 保守墙位兜底；炸弹/眩晕法宝应急预算；TTF 提前召回 |
| 夜间采矿被机器人路径覆盖 | 工人阵亡+经济中断 | U6 验证后再开放；矿点白名单制 |
| 火箭3回合冷却空窗被大怪压境 | 墙被突破 | 电磁炮补持续火力；冷却期走位/炸弹填空 |
| LLM 3次/日限制 | 宝藏/任务推断受限 | 任务期间集中使用；本地规则引擎优先 |
| 操控武器消耗动作的语义不明 | 夜防指令全废 | U4 第一夜优先验证 |
